# Security policy

This repository contains only public recruiter-facing portfolio material.

## What belongs here

- Public professional biography
- High-level project descriptions
- Links to already published work, such as the master's thesis on Theseus
- Static website source for GitHub Pages

## What does not belong here

Commercial implementation details are intentionally excluded. Do not commit:

- Credentials, API keys, tokens, certificates, or `.env` files
- Customer names, customer data, or private correspondence
- Internal architecture, proprietary thresholds, policy logic, or unreleased product functionality
- Training data, private documentation, or source code from other commercial projects
- Business-plan, visa, or commercialization materials

If you find a secret in this repository, rotate the credential immediately and open a GitHub issue or contact the maintainer privately. Do not paste the secret into the issue.
