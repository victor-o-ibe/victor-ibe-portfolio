# Victor Ibe technical portfolio

Public site for Victor Ibe, covering AWS, cloud architecture, AI/ML systems and MLOps.

Live site: https://victor-o-ibe.github.io/victor-ibe-portfolio/

Repository: https://github.com/victor-o-ibe/victor-ibe-portfolio

## Local development

```bash
npm install
npm run dev
npm run check
npm run build
```

Personal and project copy live in `src/data/portfolio.ts` and `src/data/projects.ts`.

The GitHub Pages source should remain GitHub Actions. The site is published at `/victor-ibe-portfolio/`.

This repository contains only public portfolio material. It does not include proprietary source, internal roadmaps, customer data, or unpublished implementation details.
